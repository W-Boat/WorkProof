# 桌面端变更

## 2026-11-11（待 Actions 验收）

- 首轮回归发现编辑区会先处理 Ctrl+K，已改为应用层优先接收并显式保留快捷键记录；测试改用实际的“文档名称”标签。文字统计改以原生输入路径建立跨浏览器样本，保留原字符断言继续核对 WebKit 行为，不放宽为任意计数。

- 保留官方 Fluent 控件、系统字体、深浅主题、两层编辑栏与现有折叠逻辑。标题栏增加图标化快捷命令，可用 Ctrl+K 搜索功能、起稿模板与最近的内置文档，支持方向键、Enter 与 Escape。
- 内置编辑器增加会议记录、阅读笔记、文章提纲。模板正文按导入事务记录，保留模板来源；新建或切换前先保存，失败时不替换当前正文。Ctrl+N 可新建空白文档。
- 文档库支持按最近修改或名称排序并保存偏好，显示搜索/来源筛选后的匹配数量。状态栏字符数可打开详细统计，按 Unicode 字符统计汉字、英文词与段落，不读取其他文件。
- 新增三浏览器检查：命令检索与键盘执行、模板导入动作、最近文档继续编辑、Unicode 统计、排序偏好，以及保存失败时保留当前内容。构建和自动测试仅在 Actions 执行，未替换本机安装。

## 2026-11-05（待 Actions 验收）

- Windows普通安装包的同源码网页/Wasm/扩展资源独立准备，不再等待Blender系统安装。原完整协议、浏览器和真实Blender验收保留，任一失败仍使整体工作流失败；不把Windows单项打包当作整体验收通过。

- 更正应用侧栏授权状态文案：授权可在宿主关闭后继续有效，因此显示“已允许/未允许”，不再将授权列表直接称为当前在线连接；实际记录状态继续由宿主确认。

- Windows安装包验收失败后修复CI准备：先按锁文件获取目标平台依赖，再离线收集许可；路径夹具清除Windows环境变量大小写变体，并让路径/平台测试中的外部命令失败立即终止步骤，避免被后续成功命令覆盖。

- 本机只读配置检查发现7b40abb包中的旧辅助脚本在Windows PowerShell 5.1下因UTF-8无BOM导致中文解析失败。打包时只为自有根目录PowerShell脚本补BOM，再计算摘要；新增真实5.1运行时逐文件解析验收。保留原下载包，不修改已核对产物。

- 新增Windows Actions原生UIA验收：独立启动本次桌面程序，检查无系统标题栏、内部最小化、最大化/还原以及关闭窗口后同进程记录端口仍工作。使用隔离目录，仅清理自行启动的进程；尚待实际运行结果。

- 普通Windows安装包新增Office首次配置资源：云端构建Word/PPT的32/64位DLL，使用现有打包工具记录源码与摘要，随NSIS安装到office子目录。新增实际NSIS安装后的资源逐项摘要检查；该新版尚未通过Actions，不等同真实Office安装成功。

- 首次安装后保留Word/PPT双方材料与桌面配置工具，避免安装一种宿主后丢失另一种宿主的配置能力；增加复制后实际文件摘要检查。原生配置命令互斥，脚本输出保持独立JSON状态。

- Windows工作台隐藏系统标题栏，内部提供最小化、最大化/还原和关闭，标题区域拖动与双击操作走受限原生命令；关闭保留托盘记录服务。
- Office完整便携包内增加首次配置入口，复用现有每用户安装器，先要求宿主退出，再复制到按源码隔离的安装目录并复核注册。缺少安装材料的独立桌面包明确提示，不假报安装成功。新增UI模拟链路仍不等同真实Office安装验收。

- 参考用户提供的CC Switch布局，在侧栏展示六种宿主与真实授权连接状态，增加当前软件连接提示；VS Code/Blender没有授权列表数据时明确指向宿主查看，不伪造连接/记录状态。
- 设置中增加浅色、深色、跟随系统，使用同一套共享设计令牌，保留选择并响应系统外观变化。新增三浏览器交互和双主题截图检查，尚待对应Actions。

- 按Windows桌面软件形态调整：固定左侧导航、独立功能工作区、底部状态栏和内容区独立滚动；移除宣传标题与装饰证书，保留系统窗口边框。导航切换不重载页面、不丢失宿主选择和操作状态。

- 工作台复用机构网页的珍珠玻璃设计令牌与原始品牌图片，采用双列布局和窄窗单列布局，突出开始记录和核验分享。
- 记住宿主选择，显示安装条件；高级证书签发和CA检查折叠展示。
- 启动与安装期间阻止重复提交；服务异常禁用启动并可刷新恢复；错误后自动展开安装说明；轮询避免重入。
- 托盘入口可恢复已最小化窗口；累计数量与宿主真实记录状态分别说明。
- 新增三浏览器真实静态页面专项与截图，IPC使用合成响应，真实宿主和原生Webview仍由独立任务验收。
