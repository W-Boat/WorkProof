      记录哪些动作？

      内置编辑器保存全部 Tiptap 事务，以及键盘、输入、选区、复制粘贴、拖放和输入法合成事件。复制等命令只表示操作被触发；不读取剪贴板中与本文无关的内容。输入法合成后的文字修改会作为编辑事务保存。

      过程页展示最近 120 个保存版本及最近 300 条操作，较早的操作仍保存在本机并纳入导出证书。

      图片与 PDF 证书

      图片 / PDF 内嵌证书工具需要签发机构的证书或可信 CA 文件
      检查作品内嵌的创作证书

      用于已经封装证书的 PNG、JPEG 或 PDF。先选择作品，再选择从签发方等独立可信渠道取得的 CA 文件（PEM 格式）。无需上传文件。

      请选择你确认可信的 CA；不要仅因它与作品一起收到就信任它。成功只表示签名、作品匹配和已披露记录通过检查，不认证作者身份、实际创作时间或原创性，也不查询撤销。

      选择作品和 CA，开始检查

      把创作证书放进作品

      准备原始 PNG/JPEG/PDF、与它匹配的 .wproof，以及你有权使用的 ES256 签名证书链和对应私钥（PEM）。没有签名凭据时，请先向签发机构申请；你仍可直接交付作品和 .wproof。

      1. 确认所选证书内容可以公开。
      2. 在系统窗口中依次选择原文件、创作证书、签名链和私钥。
      3. 为新文件选择保存位置，已有文件不会覆盖。

      PDF 目前支持未加密、未签署且不含压缩对象流的文件；不支持时，可交付作品和 .wproof。拿到新文件的人可以读取证书中的文件名、时间和所披露的过程记录；建议先使用选择性披露证书。私钥仅由本地一次性工具读取，不上传或保存到后台。

      选择材料，生成带证书的作品

      生成新文件不等于通过独立 CA 信任检查，也不证明作者身份或原创性。完成后可用上方入口另行核验。
