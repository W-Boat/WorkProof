# WorkProof Blender 插件

需要 Blender 4.2+ 与已启动的 WorkProof 桌面引擎。无额外 Python 依赖，自动发现本地引擎。

在 Blender 设置 → Get Extensions → Install from Disk 中选择 Actions 产物 `workproof-blender-0.2.0.zip`。开启插件，视图侧栏出现 WorkProof 面板。先保存工程，再点击开始记录；完成后点击保存并导出。`.wproof` 保存在工程旁边，与 `.blend` 一起核验。

采集网格顶点/边/面数、对象数、修改器数、网格变化信号、撤销/重做、保存、暂停与恢复。采集器不保存几何坐标、网格内容或对象名称；导出时本机引擎读取最终工程计算摘要。依赖图回调只标记脏状态，至多每秒采样一次。网络放到有限队列的后台线程，不在 bpy 回调内执行网络请求。

无法采集的内容包括视口旋转、逐笔压感及精确修改器参数演进；不会通过已有统计推断这些数据。暂停和断连会暴露缺口。插件卸载或工程切换会结束当前记录，未导出的内存队列不会成为证书。

宿主操作系统和 Blender 本身可能要求确认扩展加载/网络权限；用户需安装宿主软件。CI 使用真实 Blender 在后台模式创建并保存工程，检查最终字节绑定与统计指标篡改检测；它不能替代交互界面的完整人工验收。
