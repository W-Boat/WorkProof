# 本机引擎子进程限制

RunEngine 使用显式可执行文件路径，不经过 shell。子进程先以 suspended 创建，加入 kill-on-close Job Object 后才执行；无法加入时拒绝运行。只继承专用合并输出管道和 NUL 输入，不继承 Word 的其他句柄。

输出通过 PeekNamedPipe 检查已有字节再读取。启动、读取、退出共用 60 秒期限，总输出最多 1 MiB。超时、超量、管道或退出失败终止受控 Job，清空输出；给用户的错误不拼接 stderr 或内部文件路径。子孙进程持有 stdout 但父进程已退出时，期限仍生效。正常完成后关闭 Job 也清理仍存活的受控子孙。

这是同步调用，等待期间 Word 界面仍可能卡顿最多约 60 秒，并非后台无阻塞实现。OS API 本身的调度/终止延迟不受严格实时保证；不将此限制称为内存沙箱。后续应把无 COM 的引擎工作移至后台并将结果送回 UI 线程。

test_process.cpp 是独立原生 Windows probe，同一可执行文件含普通输出、挂起、超量输出和父进程退出后子孙仍持有 stdout 的真实进程 fixture。测试缩短期限但使用相同 helper；只允许在 Actions 构建与运行，不在用户本机运行。通过这些 fixture 不代表所有真实 Word 交互已经验收。
