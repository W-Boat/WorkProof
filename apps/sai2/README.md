# PaintTool SAI2 接入要求

Windows 客户端已接入 SAI2 保存版本记录，首个带此功能的安装包 `6707485` 已在本机安装启动。双平台核心检查和 Windows 原生控制器检查已通过。实际 SAI2 宿主验收待软件可用后进行。安装包及后续版本见[绘画交付记录](../../docs/DRAWING-ADAPTERS.md#最新绘画交付核对)。

在“应用连接”选择“SAI2 · 保存版本”，通过系统文件选择器选定一份已有的 `.sai2` 文件。保持 WorkProof 运行。完成绘画后先在 SAI2 保存，再回到 WorkProof 导出证书。原文件和证书一起交付。

后台约每两秒查看所选文件的状态，观测到稳定变化后分块计算 BLAKE3，签入保存事件。轮询可能错过短时间内连续的保存。记录仍会出现在“我的文档”，可以暂停、继续和导出。作品移动后会暂停，应将它放回原位置再继续。关闭 WorkProof 后，已保存的记录仍在文件列表，当前观察会话不会自动恢复。

[官方开发室](https://www.systemax.jp/en/sai/devdept.html)提供 SAI2 可执行版本与开发说明。截至本次核查，页面没有提供足以实施完整图层与笔触记录的公开插件 API 文档；这不是证明所有扩展方式均不存在。后续如取得可靠的公开接口，再补原生语义记录。

当前记录覆盖选定文件的已保存字节与指纹。客户端不观察画布内容、应用内动作、图层或笔触，也无法确认保存由哪个进程触发。暂停期间的变化在证书中标注为缺口。保存中或导出时仍在变化的文件会提示重试。最终核验以随证书交付的文件字节为准。

实际验收需要合法可运行、可保存文件的 SAI2，分别检查用户指定版本；不捆绑商业软件、激活证书或绕过试用限制。当前不声称 2026 稳定版、改版预览或全部历史版本已兼容。
