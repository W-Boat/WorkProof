# PaintTool SAI2 接入要求

SAI2 已列入用户指定的优先宿主，目前尚未实现，不能在客户端显示为“已支持”。此文是实施要求，不是功能交付。

首先覆盖 Windows 的 `.sai2` 本地作品。用户主动选择文件并开始后，应在 WorkProof 的文件列表展示来源、记录状态、暂停/继续、保存版本和证书；默认由外部 SAI2 打开作品。记录必须绑定该文件和经过核对的进程，进程退出、文件改名/另存或切换作品时分别处理，不能混记。

[官方开发室](https://www.systemax.jp/en/sai/devdept.html)提供 SAI2 可执行版本与开发说明。截至本次核查，页面没有提供足以实施完整图层与笔触记录的公开插件 API 文档；这不是证明所有扩展方式均不存在。后续如取得可靠的公开接口，再补原生语义记录。

现阶段拟实现显式开启的外部记录方式：文件保存变化和指纹、只在指定应用获得前台焦点时统计的有限操作类别。点击和快捷键触发不能标成完成一笔绘画、成功撤销或真实人类创作；不读取全局文字、密码、剪贴板内容或其他应用的操作。缺少画布/文档内语义时，在报告中列明“未采集图层/笔触”。

文件稳定性需要防止保存中的半成品摘要，支持替换式保存、保存失败、断线、暂存及有界重试；只有确认的保存版本才能绑定最终作品与证书。大文件必须流式计算，禁止一次读完整原生作品。进程观察和文件变化不是官方软件身份认证。

实际验收需要合法可运行、可保存文件的 SAI2，分别检查用户指定版本；不捆绑商业软件、激活证书或绕过试用限制。当前不声称 2026 稳定版、改版预览或全部历史版本已兼容。
