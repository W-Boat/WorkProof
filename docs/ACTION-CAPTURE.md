# 细分动作记录

本次扩展包含采集、签名、浏览器核验和统计图表。源码实现不等于真实 Office 验收完成，新增流程须通过 Actions 并在目标宿主中验收后交付。

Word/PPT 原生插件仅在自己的 Office UI 线程安装消息观察器，并限制到当前记录文档窗口内的已知编辑控件类；暂停、其他窗口、对话框和任务栏输入不采集。退格、向前删除、空格、回车、复制、粘贴、剪切、撤销、重做、格式快捷键和光标移动只累计次数，每次采样合并成 `interaction` 事件。不会保存实际按键文本、剪贴板、选中文字、内容位置或窗口句柄。鼠标菜单、触屏和输入法覆盖不完整，不能称为全部操作；未识别编辑控件不会放宽为全局键盘监听。

指令不等于执行结果。例如复制快捷键可以没有复制内容，重做可以没有可重做操作。图表将“捕获到的键盘操作”与“观察到的文档变化”分开。没有采集数据时显示未采集，不补零。计数通过既有 BLAKE3 链和签名提交，修改计数会改变事件摘要。

Word 可选采样相同选区的粗体、斜体、下划线、字号以及段落对齐、段前段后距离和行距；选区变化时不推断格式修改。页面方向、尺寸与边距采样比较生成版式变化。PPT 当前只比较页面宽高，格式快捷键属于指令计数，尚未覆盖所有对象格式、主题和母版。比较所用数值只留在进程内，记录中不附具体格式值。每 1.5 秒比较可能合并短时多次修改，也可能漏掉修改后迅速恢复原样的操作。

VS Code 保留官方撤销/重做事件来源，增加实际新增的空格和换行数量；这些是文本变更结果，不称为空格键、回车键或粘贴次数。WPS、Office.js、Photoshop、Blender 尚未同步提供此键盘计数能力，不将协议支持等同于宿主支持。

核验页及桌面内嵌核验页共用 `ActionBreakdown`，完整和选择性披露均只合计所提供记录。选择性披露的统计不能代表未披露部分。示例 `actions-demo` 明确为合成数据；浏览器检查经过真实 Rust 签名与 Wasm 核验，不作为真实 Office 记录证据。

协议保留现有封套与哈希编码，新增事件类型与数值指标白名单。旧版严格核验器可能拒绝新记录，请随配套包更新；未收紧或绕过未知指标与计数上限检查。新增原生分类检查在 x86/x64 Actions 上运行，宿主窗口句柄和真实输入路径另需 Office 实测。
