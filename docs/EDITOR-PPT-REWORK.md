# 编辑器与 PowerPoint 采集改进

本阶段已在 `8d85093` 实现并交付：编辑器底栏缩放与字数统计、每份文档记录上限、Office 重连间隔与次数、Word/PPT 分别设置自动开始，以及 PPT 文字与基础格式采样修复。详情、Actions 证据和安装摘要见 [2026-11-14 桌面交付](DESKTOP-DELIVERY-2026-11-14.md)。

## 实现范围

缩放比例为 50%—200%，工具栏折叠后仍可访问。Word、Markdown 分别应用缩放，统计区分汉字、英文词与 UTF-16 字符数量。

记录上限由本机核心持久化并在收集器与编辑器执行，拒绝新编辑后保留原记录；精确重试仍然幂等，为导出及缺口预留协议容量。Office 断线重试保留同一事件的序号及字节，达到次数上限暂停；连接授权失效仍需批准。

PPT 遍历文本框、分组、表格、SmartArt，补全字符/段落计数与等长替换识别，支持基本字体和段落格式；文字仅在本机计算统计和变化摘要，不写入公开事件。文字扫描最多 32 层、4096 个对象、800 万 UTF-16 单元，100ms 预算在 COM 调用边界检查，无法抢占单次同步调用。采样不完整与完整稳定状态分别处理。

自动开始默认关闭，在设置中分别启用 Word 或 PPT。仅对已保存、可编辑的本地文件生效；客户端需在线，首次连接需批准，手动暂停同一文档保持暂停。
