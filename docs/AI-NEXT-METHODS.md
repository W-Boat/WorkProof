# 新检测方法与评估数据的接入核查

现有 MPU v3 中英文配置属于同一检测方法，不能按两个独立方法计算。下面只是核查候选，不代表已接入、已商用放行或已证明效果。

- Desklib v1.01：官方模型卡说明为英文 DeBERTa-v3-large 分类器，采用池化与单 logit/sigmoid。与 MPU 是不同模型实现，仍属于监督分类方法，不能据此声称覆盖多类独立检测原理。模型卡标 MIT，但目前只核对了该声明；源码、权重与基座的完整许可和版本还需固定检查。其分数也不能当作 AI 内容比例，不能套用现有 softmax 评估策略。来源：[官方模型卡](https://huggingface.co/desklib/ai-text-detector-v1.01/blob/main/README.md)、[官方源码说明](https://github.com/desklib/ai-text-detector)。
- C-ReD：作者发布的 2026 中文基准候选，覆盖多领域与生成器，适合继续核查近期中文评估数据。仍需确定不可变数据版本、逐类生成器及时间、人工文本来源、许可、校准/评估切分与训练泄漏；尚未下载或用于准确率结论。根 LICENSE 路径本轮返回 404，这只说明该路径不可用，不能替代完整目录和数据许可审查。来源：[作者仓库](https://github.com/HeraldofLight/C-ReD)。
