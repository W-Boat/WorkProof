# 加密 HTML 核验报告

在核验结果中点击“下载报告”，设置并确认至少 8 个字符的密码，然后保存。原作品另附，HTML 只保留作品名称、类型、大小和核验得到的指纹，不封装原作品字节。

报告包含生成时的文件匹配、记录链、签名、默克尔归属及指定证书指纹核对结果；全部已披露事件及其指标、检查点和哈希；原始 `.wproof` 文件的精确字节；全部检验指标、测量值、阈值、规则版本及已返回提醒；雷达图、参考区间和十种统计图；已完成的文件属性检查、生成时显示的辅助检查文本及可用的客户端构建信息。

记录在 HTML 中完整保留，查看时每页显示 200 条，避免一次创建大量表格节点。散点图最多绘制 500 个代表点，原始事件不会因此删除。仅披露部分事件的证书不会补出隐藏记录，相关全程时间统计会标为范围不足。未执行或失败的辅助检查保留对应状态，不伪装成检查完成。元数据检查沿用解析器既有的范围和字段限制。

## 保存与 MD5 关联

客户端使用原生保存对话框，成功后得到四个同名配套文件：

- `WorkProof-report.html`：加密报告。
- `WorkProof-report.html.md5`：这份 HTML 精确字节的 MD5。
- `WorkProof-report.html.sha256`：同一文件的 SHA-256。
- `WorkProof-report.html.report.json`：文件名、字节数、两个摘要和原证书指纹的关联清单。

文件名以用户实际选择为准。配套文件已存在时拒绝覆盖；写入失败会清理本次创建的文件，不删除原有文件。关联清单最后写入。这不是跨文件、跨崩溃的原子事务。只有保存成功后才显示摘要。

独立网页使用浏览器下载 HTML，随后提供单独的“保存 MD5 校验文件”和“保存关联清单”操作，避免浏览器阻止连续自动下载。清单也包含 SHA-256。文件重命名不会改变摘要；网页校验单中的名称是发起下载时的建议名称。

HTML 不把自己的 MD5 写回自身，否则写入摘要又会改变文件。MD5 与 SHA-256 位于外部校验文件、关联清单及保存结果中。它们用于核对报告文件，不能代替原证书签名，也不提供官方发布者身份。

## 离线打开

接收者下载 HTML，用支持 WebCrypto 的完整浏览器打开，输入提供者单独告知的密码。报告附带图表运行代码和许可文本，不依赖 CDN，也不上传内容。解密后可下载原始证书及未加密的完整报告数据 JSON；复核原作品时仍需另附的原文件。

加密采用浏览器 WebCrypto 的 AES-256-GCM；密码通过 PBKDF2-SHA256、600,000 次迭代和独立随机 16 字节盐派生密钥，使用随机 12 字节 IV。渲染组件 SHA-256 纳入认证附加数据。密码与派生密钥不写入报告；生成器仅保存密文。报告生成时间与核验结论是导出时的快照，不是可信外部时间凭据。

单份证书最多 32 MB，完整报告明文最多 80 MB，生成后的 HTML 最多 128 MB；超限明确失败，不截断记录。选择或更换原作品仍由既有核验流程处理，报告封装不会重新读取作品字节。
