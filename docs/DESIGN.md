# 设计与验收约束

- 石墨色工作台、暖白证书、青绿色提示；避免将未知状态包装为认证成功。
- 文件匹配、记录完整性、签名有效是三个独立结果。
- 身份、外部时间、来源信息分别标注，不给“人类比例”。
- 核验进度来自真实 Worker；取消直接终止 Worker。
- 核验失败禁用证书导出；未知版本或非法 JSON 为错误，不降级放行。
- 支持键盘操作、减少动态效果偏好和 390px 移动布局。
- 导出的图片和 PDF 是报告，不是新的可信凭据。复核需要作品和 `.wproof`。
- 首版只保留真实时间轴；未来宿主支持结构化演进事件后，再引入图层或 AST 树。

性能预算需实测：常驻进程树内存目标 50 MB，空闲 CPU 平均低于 0.5%；这些是目标，未测前不得宣传为结果。
