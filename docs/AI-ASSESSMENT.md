# AI辅助判断阶段（开发中）

首个源码增量fcab99a已提供浏览器内可选PNG文字元数据检查，使用一次性Worker、256MiB文件/4096块/单字段256KiB/文字总量1MiB/32显示项限制和15秒超时，可取消。仅展示未压缩tEXt/iTXt，压缩文字、过大或异常字段明确计数未检查；prompt/workflow/parameters字段名称只标记为可修改的线索，不输出AI比例。C2PA存在仅作提示，不冒充签名验证。无需证书也可对选定作品执行，未新增依赖，不联网。该增量的浏览器验收仍以对应Actions结果为准；检测模型、水印、JPEG、DOCX和PDF解析仍未接入，不能把PNG字段检查说成多引擎检测已完成。

2026-11-01新增要求：接入目前大多数开源AI检测引擎，在元数据和文件内容中寻找AI指纹，作为辅助判断。现阶段是明确需求与接入清单，不是已完成或已支持声明；不缩减原有宿主、互操作和机构服务目标。

## 用户流程

1. 先查看作品与签名证书是否一致。该密码学结果独立保留。
2. 用户选择“进一步检查AI线索”，查看将分析什么、在哪里运行、是否需要向机构发送内容，再明确启动。
3. 分组展示“文件中的标记”“水印与来源凭据”“检测引擎的参考结果”。每项给出发现位置、方法、版本和含义；不支持、未配置、超时与未检出分开显示。
4. 冲突时直接列出冲突；由人结合创作过程作判断，不自动处分学生或判定作者造假。

大型模型在可选本机进程或独立机构服务中按需运行，不进入常驻记录守护进程。默认不上传作品；选择机构分析时单独确认具体内容范围。模型下载列明大小与许可证，不自动下载不明权重或执行远程自定义模型代码。

模型代码和权重必须锁定并核对摘要；优先使用不执行对象反序列化的权重格式，不能因为下载自模型站点就运行任意Python代码或不受限的pickle加载。支持状态与“已下载”“已加载”“通过真实验收”分别记录。

## 元数据与文件线索

- PNG/JPEG：结构化Software/Comment/XMP字段、生成器工作流或参数字段、IPTC数字来源类型、C2PA断言；不把普通Photoshop软件标记当作AI证据。
- DOCX/WPS OOXML：文档属性、生成工具、外部关系及可识别的生成标记；限定ZIP条目、压缩比和展开总量，禁止执行宏、加载外部链接或访问未授权文件。
- PDF：受限元数据/XMP/附加来源信息；不执行脚本、启动附件或自动联网。
- 内容层：只调用明确支持该语言与模态的引擎。引用“ChatGPT”等文字、普通编辑器标记、文件没有EXIF均不能单独定为AI生成。

每条线索保留原字段名、位置与经过隐私裁剪的值，并标注“可被修改的元数据”“统计参考”“在指定信任范围内核验的签名/水印”。元数据可删改；未检出不代表没有使用AI，检出可伪造的工具字符串也不证明真实生成来源。

## 结果协议与验收

结果至少含engine_id、engine_version、model_revision、input_hash、支持的语言/模态、status、原始score及score_kind、校准版本、限制和耗时。status区分completed、not_configured、unsupported、insufficient_input、timeout、cancelled、error。原始logit、困惑度、p值、校准概率不得混为同一“AI概率”，不得把相关引擎分数直接平均或将失败计作0。

真实验收包括中文/英文、人类原作、AI样本、引用、短文本、混合编辑、改写与翻译，以及图片裁切/压缩/截图/普通编辑软件导出。记录各类误报/漏报及样本来源，不只报总体准确率。加入缺模型/离线/并发/超时/取消、权限、隐私和ZIP炸弹/畸形元数据测试。报告与原签名证书分别存储，追加分析不能回写或替换原签名。
