# 检查图片中的创作证书

验证进展：源码 `794e7d0` 的 [Windows Office 专项 41390430072](https://github.com/W-Boat/WorkProof/actions/runs/41390430072) 已全部成功，包含桌面实际编译、真实签署 PNG/基线与渐进 JPEG 报告兼容检查，以及超时、超量输出、完整/选择性披露语义的四项桌面测试。该源码对应四平台总流程因旧 Word 文案断言失败，后续 `e0eac77` 已修正断言并重新提交；不能以 Windows 通过替代 macOS/Linux 桌面入口验收。新安装包的真实点击流程也尚未验收。

此入口用于已经嵌入 C2PA 与 WorkProof 过程证据的 PNG / JPEG。普通作品与独立 `.wproof` 文件，仍从“检查作品和证书”进入配对核验。

## 操作步骤

1. 打开 WorkProof，展开“检查图片内嵌的创作证书”。
2. 点击“选择图片和 CA，开始检查”，在系统窗口中选择图片。
3. 选择从独立可信渠道取得的 PEM 格式 CA 文件。不要仅因为 CA 与图片一同收到，就认定其可信。
4. 查看结果。关闭或取消文件选择会结束本次操作；原文件不会被改写，也不会上传。

完整证据通过时，显示图片匹配、签名、完整过程记录与所选 CA 信任检查通过。选择性披露通过时，显示已公开记录数量和总记录数量；未公开记录不属于本次检查范围。失败会给出原因或重试建议，不自动认定 AI 创作或抄袭。

通过检查不等于认证作者身份、实际创作时间、原创性或人类创作比例。本入口不查询证书撤销状态；接收方仍需自行确定所选 CA 的可信来源。

## 实现与验证范围

桌面只在用户点击后运行随安装包提供的一次性核验工具。图片和 CA 路径不进入网页，网页只接收经过检查的结果摘要。独立 SDK 不加入记录守护进程依赖；安装包附带工具锁文件、许可材料和构建来源。

图片最多 96 MiB，CA 文件最多 256 KiB；核验运行时间限制 60 秒，标准输出和错误输出分别限制 1 MiB。文件选择窗口最多等待 5 分钟。当前实现停止超时的直接子进程，不提供通用后代进程树沙箱；随包 CLI 不派生外部命令。

Linux DEB 声明 zenity 依赖，需要桌面图形会话。Windows 使用系统文件选择窗口，macOS 使用系统选择窗口。

本增量已接入 GitHub Actions：用实际签署的 PNG、基线/渐进 JPEG，分别生成完整和选择性披露报告，交给桌面结果解析器检查，同时覆盖失败字段、超量输出和超时。代码已接入不表示已通过；结果以本次对应工作流为准。真实用户点击流程仍需安装产物后验收。
