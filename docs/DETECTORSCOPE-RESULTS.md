# DetectorScope 中英文留出评估

在冻结的双语留出集上，当前 DetectorScope 配置漏掉 66.15% 的英文生成样本和 88.54% 的中文生成样本。此配置保留为研究配置。评估采用固定 float16 权重、logreg 分类头及 `tau=0.85`，每种语言分别用 384 份校准样本冻结阈值。[原始校准](https://github.com/W-Boat/WorkProof/actions/runs/42857716376) · [留出评分](https://github.com/W-Boat/WorkProof/actions/runs/42950474175) · [独立复核报告](https://github.com/W-Boat/WorkProof/actions/runs/42977755904/artifacts/13836590253)

| 语言 | 完成评分 | 人工样本误报（95% Wilson 区间） | 生成样本漏报（95% Wilson 区间） |
| --- | ---: | ---: | ---: |
| 英文 | 384/384 | 11/192，5.73%（3.23–9.97%） | 127/192，66.15%（59.19–72.46%） |
| 中文 | 383/384 | 12/191，6.28%（3.63–10.66%） | 170/192，88.54%（83.26–92.31%） |

中文有一份人工样本超过固定 512 token 上限，保留为超范围。留出集采用公开数据的来源标签，相关样本可能使区间偏窄。数值适用于这批样本和固定配置。复核检查了归档摘要、冻结样本身份、转换记录连续性及统计计算。核验范围见[复核任务](https://github.com/W-Boat/WorkProof/actions/runs/42977755904)。
