# 2026 检测方法二次来源核查

核查日期：2026-11-10。仅浏览原作者/发布平台资料，未复制执行候选代码、安装依赖或下载模型；当前生产引擎列表不变。以下浮动页面还需固定提交和文件摘要，不能直接作为分发许可清单。

## NTS：温度敏感性

[ACL 2026 论文页](https://aclanthology.org/2026.acl-long.1748/)提出归一化温度敏感性，属于统计检测方法，不是把现有 MPU 分类器换个名称。页面列出[作者代码](https://github.com/Shixuan-Ma/NTS)。

当前 README 的复现实验使用 Falcon-7B，作者硬件为 48 GB A40。它不能据此被标为普通用户电脑可轻量运行。所浏览根目录未见独立 LICENSE 条目，代码、模型和数据的具体授权尚未核清；不能把“公开 GitHub 仓库”视为商业分发许可。接下来应固定代码版本、核对原始公式与授权，再决定是否可在隔离 Actions 中使用现代小模型进行资源和中英文留出评估。更换模型后的效果不能继承论文阈值。

## PAWN++：新监督方案，代码与模型声明需分开处理

[2026 论文页](https://aclanthology.org/2026.wac-1.25/)报告真实网页改写场景下效果明显下降，不能只采用其域内结果作为部署准确率。

[作者模型卡](https://huggingface.co/crayden/pawnplus)标注英文、512 token 上限，使用 Llama-3.2-1B-Instruct 和 Llama-3.2-1B 两个冻结骨干及轻量分类头，并声明模型卡许可 MIT。[作者代码仓库](https://github.com/HSE-Team-142/automatic-goggles)则显示 AGPL-3.0。模型卡的声明不能覆盖代码和骨干模型各自条款，目前不作整套商用许可已核清结论。

需分别审查代码、头部权重、两套骨干和训练数据；确认访问条件、固定真实权重，再进行限定长度的真实推理和中英文误报评估。模型卡明确英文，不从多语言基准推导已支持中文。它可增加新检测方案，但仍属监督检测，不能当成额外水印或统计方法。

## SpecDetect：发表年与首次公开年不同

[AAAI 2026 发布页](https://ojs.aaai.org/index.php/AAAI/article/view/40510)与[作者预印本](https://arxiv.org/abs/2508.11343)显示该方法采用 token 对数概率序列的频谱特征；预印本编号为 2025 年。它符合“2026 会议发表”的口径，不能直接写成“2026 年首次提出”。本次发布页直接访问被站点阻拦，仅核对到发布平台搜索摘要及预印本元信息；尚未核对完整实现、授权和评分公式，不接入产品。

## DetectZoo：候选聚合层，不把所有算法重新计为 2026

[作者工具仓库](https://github.com/sadjadeb/DetectZoo)提供多模态统一接口，并包含旧检测方法、自动缓存模型和数据的路径。其 2026 工具论文不使收录的旧方法变成 2026 新算法。默认全模态依赖和自动下载行为也需要与 WorkProof 的显式选择、隐私和轻量守护进程要求隔离。

目前只将其作为方法清单和实现对照来源，未安装或纳入默认服务。逐方法权重、依赖许可、下载行为和实际资源验收缺一不可。

## 后续执行顺序

优先继续核查已有 DetectorScope 的固定权重和许可材料，其次处理 NTS 的授权与资源约束；PAWN++ 单独审查代码/模型条款。实际推理通过后才进入新的中英文校准及未观察留出集，公开误报、漏报、覆盖和资源消耗。未通过的方法保持关闭，不把一次合成运行或论文年份当成可靠性认证。
