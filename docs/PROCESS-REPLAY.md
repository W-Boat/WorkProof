# 客户端过程回放

在内置编辑器打开文档，进入“过程”，点击“过程回放”。页面参考用户提供的文档回放布局，使用客户端现有 Fluent Web Components、System Icons、深浅色和短过渡动画。独立浏览器核验页不受这项改版影响。

左侧显示所选保存版本的只读正文，下方显示操作分布、粘贴标记、进度和播放控制；右侧显示保存版本、粘贴命令、原始动作数量，以及当前版本的动作卡片。连续动作复用编辑器既有的合并规则。右侧可收起；窄窗口改为上下排列。

支持播放、暂停、1×/2×/4×/8×速度、拖动进度、前后版本和点击粘贴标记定位。版本正文按需读取，最多缓存三份；版本索引每页 128 条，不再依赖旧过程页最近 120 个版本、300 条动作的摘要。索引固定在打开回放时的文档修订号；后来保存的版本需要重新打开回放才能纳入。

回放以数据库中实际保存的版本为准，没有推算版本之间每个字出现的画面。复制、粘贴、删除、撤销等动作来自相应保存批次，能提取到的事务文字作为纯文本展示。大段粘贴提示使用本地动作分组新增至少 200 字符的条件，帮助定位内容加入的位置，不是 AI 来源判定，也不是签名证书的核验结论。

## 数据与交互边界

- 只通过受工作台权限约束的 Tauri 命令读取本机数据库。没有新增 HTTP 接口，没有上传正文，不修改编辑历史。
- 新索引命令只返回版本号、保存时间和动作汇总，不返回正文；正文及原始动作通过所选版本命令读取。数据库查询按文档和版本索引定位。
- 本次只覆盖内置编辑器保存的文档。外部 Word 等应用仅采集到统计或文件摘要时，不能据此生成正文回放。
- 一次最多整理 20,000 个版本，超出时明确拒绝打开，不截断后冒充完整历史。时间轴快捷标记最多显示最近 96 个含粘贴的版本，其余版本仍可拖动或逐个查看。操作分布固定为 64 个区间，避免为每条原始动作创建 DOM 节点。
- 保存时间倒退时保持修订顺序，并合并倒退的时间间隔；该时间轴不是独立可信时间凭据。
- 切换到其他版本时清除旧预览；读失败显示错误。关闭窗口后停止播放、丢弃迟到响应、清理缓存，并把焦点还给入口按钮。切到后台时暂停播放。
- 支持减少动态效果，正文允许选择复制，界面保留客户端禁用浏览器右键菜单的设置。
