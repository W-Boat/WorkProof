# 桌面插件连接管理

Word、WPS 网页加载项和 Photoshop 原生插件首次请求连接时，桌面工作台要求使用者明确批准。批准后，“已授权的插件连接”显示来源、宿主、已绑定会话数量与剩余授权时间。网页展示完整来源网址；原生连接明确标记自声明、身份未认证。不会返回访问令牌、文档名称、会话编号或文件路径。

“断开连接”撤销该次授予。之后使用旧令牌创建会话、追加事件或导出证书都会被拒绝，旧配对票据也不能再次取回令牌；其他已批准的连接继续工作。重新使用加载项需要重新申请并批准。重复撤销同一连接可安全完成；尚未批准的请求仍通过“拒绝”处理。过期连接会被移除。

撤销不是远程删除。SQLite 里的已采集记录、已导出的证书与作品仍保留；已经通过授权检查的在途请求可能完成。需要停止采集时，也应在宿主面板暂停或停止。此控制针对逐次授予的 Word/WPS/Photoshop 连接，不撤销现有 VS Code/Blender 的本机主令牌；退出托盘引擎会使所有内存授予失效。

Word/WPS 加载项下一次收到 `PAIRING_REQUIRED` 时暂停采样并清除内存令牌，禁止继续/导出，提示关闭并重新打开加载项、再次批准后开始新记录。原授予的会话不转移给新授予；未提交事件不能补传到新记录，也不伪装成连续采集。

连接列表与撤销仅通过 Tauri IPC 提供，没有新增 HTTP 审批、连接枚举或撤销端点。CI 专用 stdin harness 调用同一撤销函数用于验证，不随产品作为远程审批服务分发。

验证范围：Rust 单测核对元数据不含令牌/会话编号、仅撤销目标、过期清理；真实 Rust/Axum/SQLite 集成验证 Word 旧令牌被拒、WPS 不受影响、Photoshop 原生撤销与记录数量保留；浏览器用模拟 Tauri IPC 检查桌面控件、断开失败与键盘焦点。后者不称为真实桌面窗口或真实 Office/WPS 宿主验收，Windows 二进制仍需单独构建和托盘启动检查。
