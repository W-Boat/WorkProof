## 本次可用功能

- 编辑器底栏提供 50%—200% 缩放、放大/缩小按钮及字数统计；工具栏折叠后仍能使用，Word 模式与 Markdown 模式均应用缩放。
- 设置支持每份文档的动作记录上限。设置持久化到本机数据库，收集器与内置编辑器共同执行；达到上限保留已有记录，可提高上限继续。保存、暂停和缺口等收尾事件预留空间，仍受协议硬上限限制。
- Windows 原生 Word/PPT 加载项支持设置断线重试间隔（1—60 秒）和最多重试次数（0—10 次）。重发保留原事件序号与内容；授权失效需要重新连接。
- 设置 → 记录中可分别开启 Word、PowerPoint 的“打开文档后自动记录”，默认关闭。WorkProof 正在运行、加载项已安装且连接获准时，打开已保存且可编辑的本地文件可自动开始；首次连接仍需批准，手动暂停同一文档不会被自动恢复。
- PPT 增加文本框、分组、表格及 SmartArt 文字采样，修复新增/删除数量固定为零；支持识别等长文字替换与基础字体、段落格式变化。扫描不完整时明确显示缺口。
- 记录上限导致导出受阻时，用户可以取消并保留待提交动作，或确认用缺口标注未保存部分后继续导出；不静默截断历史。
