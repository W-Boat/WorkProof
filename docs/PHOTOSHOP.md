# Photoshop 采集与原生授权

自有 UXP 代码在 `apps/photoshop`。使用明确的生产动作订阅列表，回调只检查当前文档 ID、数值路由提示和合并动作类别；不调用 `['all']`、批量读取像素或保存描述符。每秒在宿主线程统计图层、组与可见节点，历史状态 ID 只在内存用于变化与并发检测。具体操作与真实验收限制见 [插件说明](../apps/photoshop/README.md)。

## 原生授予流程

`POST /v1/native-pairing` 仅接受无 Origin 的原生 JSON 请求且 `source=photoshop`，返回随机票据；`GET /v1/native-pairing/{ticket}` 轮询结果。授权前不给令牌，桌面端显示“本机插件自声明、身份未认证”，由使用者明确允许。拒绝/过期后票据失效。票据与授予保存在当前进程内，未批准票据有效 120 秒，已批准授予有效 8 小时。

原生与浏览器是不同通道，不能互换票据和令牌；任何带 Origin 的请求都不能使用原生通道。令牌仅可创建 Photoshop 来源会话、追加与导出其自己绑定的会话，不可查询全局状态、读取其他会话或调用本机路径 `/seal`。主令牌仍供既有本机 VS Code/Blender 使用，不发给 UXP。浏览器 Word/WPS 的来源与会话隔离保留。

这不是 Adobe 插件身份认证。拥有本机权限的其他进程仍可发起自声明请求，必须仅允许刚刚由当前 Photoshop 面板发起的请求；控制当前用户和签名密钥的攻击者仍可伪造记录。

## 文件绑定

用户通过宿主保存选择器授权一份新的 PSD 副本和证书位置。只在显式导出时进入 modal 保存副本，以 `asCopy=true` 避免改变源文档，并拒绝与源路径相同的目标。读取已保存字节并比较大小/修改时间，计算 BLAKE3；签发前复核文档/历史状态、动作修订号和文件元数据，事件最后 checkpoint 绑定这份副本。

元数据检查发现普通并发变化，不防御本机攻击者回滚时间和内容。保存文件与证书不是跨应用事务；中断或写入失败时以界面错误为准，接收方始终需独立核对精确交付件。当前一次读取上限 128 MB，超大 PSD/PSB、所有宿主版本与 macOS 安全传输仍未完成。

## CI 验证边界

控制器测试以模拟 Adobe API 验证隐私、合并、暂停/续录、换文档、选择取消、保存异常、丢失确认重试和并发变化。

集成测试使用真实 Rust/Axum/SQLite/签名/CLI。`native_adapter_harness` 是仅在 Actions 隔离临时目录启动的示例，通过 stdin 调用与桌面按钮相同的审批函数；不是随产品提供的审批 HTTP 端点。API 权限、浏览器/原生通道隔离、来源/会话隔离及禁止 `/seal` 均有检查。集成文件字节由模拟宿主生成，仅用于文件绑定，不称为真实 Photoshop PSD 验收。

正式 `.ccx`、Adobe Marketplace 身份、真实 Windows Photoshop 加载、原生请求 Origin 行为、macOS HTTPS/其他安全传输及宿主回调性能需后续实测。不能把开发 ZIP、模拟测试或绿色 CI 标为“所有 Photoshop 版本点击安装”。
