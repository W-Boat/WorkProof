# WorkProof 浏览器体验统一

核验端面向老师、甲方与机构管理员，采用管理端已有的珍珠玻璃设计系统。浅色、深色使用同一套语义：蓝色为选择和操作，绿色为明确通过，红色为失败。证书作为可导出的纸质凭证独立排版，核验工作区不再维护另一套森林绿控件。

## 真实复用边界

管理端是 Vue 3，独立/离线核验端是 Next.js/React；Vue SFC 不会直接导入 React。核验端 `globals.css` 直接导入管理端的 tokens、base、materials、components、instruments、layout 六层源文件，主题值和控件样式只有一个来源。React 的 Button、Panel、PageHeader、Tag、TextInput、EmptyState 是薄适配，使用管理端公共组件的 DOM/CSS 契约。没有复制一套主题，也没有声称同一个 Vue 渲染组件在两个框架直接运行。

管理端登录和导航继续直接使用原 Vue 组件，并共用已生成的 WorkProof 品牌图标。上游自有组件和样式的 MIT 声明保留；GSAP 和其他第三方条款仍分别适用。本次没有更换图表库或引入新的 UI 依赖。

## 页面结构

- 页头与主操作：核验目的、当前状态、显式主题切换。
- 文件选择：两份本机文件、真实等待、取消与错误反馈。
- 核验结果：纸质证书与逐项判定并排，窄屏上下排列。
- 后续操作：图片、打印、选择性披露，以及有范围说明的过程轨迹。

业务组件位于 `apps/verifier/components`，类型与格式化工具位于 `lib/evidence.ts`。页面保留流程控制；签名和文件核验继续由独立 Worker/Wasm 执行。加载、空状态、失败、部分披露和完整证据都有对应展示。

## 交互约束

外观偏好与管理端使用同一 `scaffold.appearance` 格式。浏览器存储按来源隔离，不能将不同端口或域名描述为自动共享偏好。不可用的本机存储回退到默认浅色，不阻止核验。响应式采用管理端 820 px 窄屏断点；表单和操作可换行，文件名与摘要不撑开页面。

少量结果进场尊重减少动态设置；没有常驻粒子或假进度动画。对话框保留焦点约束与 Escape 返回。部分证据不展示完整链通过，不将未披露的事件连成曲线，PNG 和打印保留范围声明。

验证在 Actions 覆盖真实 Wasm 核验、导出再核验、篡改拒绝、主题保存、手机/平板/桌面宽度、键盘焦点与截图。管理端的品牌改动单独通过机构 Vue/Java 构建及真实服务验证。本次没有新建表、重置账号或更改认证权限。

最新交互加入“作品 → 证书 → 核验与分享”的编号引导，证书主标题 30–40 px、作品名桌面 18 px/手机 16 px、重要说明至少 13 px。核验明细用普通语言表达；算法与签名清单保留在原始详情。分享签名文件与指纹，而非仅分享可编辑的图片；接收方可粘贴独立取得的指纹再核验，详见 [签名证书分享](CERTIFICATE-SHARING.md)。
