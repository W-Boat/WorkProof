# 编辑过程提醒

密码学核验检查文件、记录链与签名是否一致。编辑过程提醒另行分析已签名的增删统计、命令计数和本机经过时间，帮助接收方找到需要了解来源的编辑片段。

当前规则为 `heuristic-2026-11-06.1`，尚未用真实中英文课程作业校准。提醒不能判断是否使用 AI，也不能认证作者身份或人类创作比例。正常粘贴、导入、语音输入、辅助工具和宿主批量采样均可能产生需要解释的变化。

## 当前规则

- 一次或一秒窗口内新增至少 500 个字符，提示大段写入。
- 总新增至少 2000 个字符，且至少 75% 位于大段写入窗口，提示集中新增。
- 连续窗口至少五秒、五次修改、300 个新增字符且速率达到每秒 30 字符，提示持续快速写入。单次大段导入不作为连续快速键入，过长的采样间隔也会中断窗口。
- 同次新增、删除均达到 300 个字符，提示成段替换。
- 内置编辑器满足最小次数、跨度、字数及间隔波动条件时，提示多个时间间隔相近。Word/WPS 的固定轮询间隔不用于这项判断。

完整阈值随分析结果提供。重复、重叠窗口会合并，最多展示八段提醒，字数占比去重计算。规则仅处理文字来源，图像和三维软件不套用文字输入结论；未知来源和数据不足显示信息不足。

## 验证与展示

共享 Rust 实现在分析前检查证书内部一致性。网页还须先核对实际文件，失败时不展示可信行为结论。选择性披露无法评估整个过程，会明确说明信息不足，不把隐藏的事件按零计算。

核验结果、过程面板、曲线标记、证书卡片、分享文字和展示图片保留过程提醒或信息不足状态。分享的原始 `.wproof` 字节不因分析而修改。点击提醒可定位相应事件，曲线在已知采集缺口处断开。

新增单元和浏览器检查由 Actions 执行。本记录描述已提交实现，实际通过范围以对应运行结果为准。
