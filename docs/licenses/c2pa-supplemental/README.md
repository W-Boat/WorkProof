# C2PA锁定依赖的补充许可材料

这些确切版本的发布包未包含可识别的独立许可文件。已验证crates.io归档checksum，读取归档内 `.cargo_vcs_info.json`，从其中的确切源码提交获取许可正文；每份材料的原始URL和SHA-256见 evidence.json。原Cargo.toml和VCS信息同时保留，便于核对版本与作者。

r-efi的许可与作者声明实际位于发布包的AUTHORS中，已保留原文，使用MIT选项；不会把其可选LGPL分支说成必须采用的唯一许可。

btree-range-map、range-traits、static-regular-grammar的对应源码提交没有独立LICENSE文件，但README明确授予Apache-2.0或MIT任选。这三项保留作者原README授权及Cargo作者元数据，选择Apache-2.0，并附Apache官方网站的完整标准正文。evidence明确标记正文是canonical-selected-license-text-not-upstream-file，不冒充上游提供的文件，也没有编造版权归属。

其余项目保留对应提交中的实际许可文件。此目录解决材料缺失并提供可追溯证据，不是对整个WorkProof或所有二进制的无条件商业发布核准。
