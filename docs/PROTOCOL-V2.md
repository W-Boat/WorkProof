# 多宿主统计扩展 v2

`workproof/2` 保留 v1 的清单、签名、文件绑定及事件序列要求，增加可选 `metrics` 对象。v2 核验器继续接受没有这些扩展的 v1 文件。

指标名白名单为 vertices（顶点）、edges（边）、faces（面）、objects（对象）、modifiers（修改器）、layers（图层）、groups（图层组）、visible_layers（可见图层）、paragraphs（段落）、characters（字符）、viewport_changes（视口变化次数）。单事件最多 16 个指标，数值 0–1,000,000,000。不存对象名、段落文本或几何坐标。未观测到的指标省略，不能用 0 代替未知。

当指标非空时，在 v1 事件的确定性二进制编码后追加 `WorkProof:metrics:v2\0`，再追加指标数量 u32 小端。按 UTF-8 键字典序依次追加 `field(key)` 和 u64 小端数值。空指标不追加任何字节，从而保留旧记录摘要。v1 清单不接受非空 metrics。

新增事件种类：mesh（网格变化）、layer（图层变化）、modifier（修改器变化）、viewport（视口变化）。事件名描述所观测的类别，不表示这个动作由真人完成。只有宿主确实提供信号时才发对应事件。

`POST /v1/sessions/{id}/seal` 供经 Bearer 鉴权的本地原生宿主使用，拒绝浏览器 Origin。请求包含绝对本地文件路径和待提交 save 事件，文件名须等于会话文件名。引擎在阻塞工作线程中流式计算 BLAKE3，检查文件大小和修改时间的一致性，追加带 checkpoint 的 save 事件并签发证据。路径及内容不持久化。

该接口不会认证调用方，拥有当前用户权限或引擎令牌的人仍可伪造输入。文件大小/修改时间检查用于发现普通并发修改，不防御有权限操纵文件元数据的攻击者。
