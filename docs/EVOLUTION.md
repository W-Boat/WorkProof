# 可核对的结构补充文件

`.wgraph` 是显式选择导出的结构补充文件，格式为 `workproof-evolution/1`。每份快照只包含会话、来源、事件编号、事件类型，以及匿名节点的类型、父节点和顺序，不包含名称、正文、坐标或图像。导出者仍应检查文件后再分享；结构本身可能透露作品组织方式。

核验页先完成作品与 `.wproof` 的正常核验，才提供“查看结构变化（可选）”。选择配套 `.wgraph` 后，独立 Worker 调用 Rust Wasm：先检查证书签名与记录链（或选择性披露的默克尔归属），再核对每份快照与已披露事件的规范化 BLAKE3 检查点。任一快照不匹配则整体拒绝，不显示未核验的节点。更换文件、取消、超时或组件卸载会终止线程，清除旧结果。

通过后可切换快照、浏览父子层级和修改器顺序；每页最多显示 100 个节点。点击“打开关系图”才加载 React Flow 画布，支持拖动画布、缩放与显示全图，不能编辑节点或关系。画布最多显示前 200 个节点，保留其真实祖先关系；完整节点仍可通过列表逐页阅读。滚轮保留页面滚动，不强制截获缩放。这里只呈现文件中提供且核对通过的结构，不补画未采集的步骤。结构核验不单独检查作品文件，也不认证身份、实际时间、原创性或完整编辑历史。主页面的作品匹配结果与结构核验结果分别显示。

关系图使用锁定的 `@xyflow/react` 开源核心，不使用 Pro 资源。每次网页构建都会从实际安装且与锁文件一致的 React Flow 声明依赖中复制原始许可文本到 `/notices/graph/`，缺少完整许可文本则停止构建。该清单只覆盖关系图库的声明依赖，不代表整个产品已完成商业授权审查。React Flow 项目许可见 https://github.com/xyflow/xyflow/blob/main/LICENSE ，交互参数见 https://reactflow.dev/api-reference/react-flow 。

协议限制为 128 份快照、每份 10,000 个节点、总共 50,000 个节点、最大深度 256、结构文件 8 MiB。节点编号必须是 JavaScript 可精确表示的正整数。拒绝重复编号、重复同级顺序、缺失父节点、循环、未知字段和未知节点类型。选择性披露的证书只能核对其中已公开事件对应的快照；其他快照须从结构文件中去除，或重新取得包含所需事件的证书。

现有 Blender / Photoshop 的旧版结构摘要不能反推为此格式，不会被自动转成结构树。适配器必须在记录时明确生成并绑定此格式的快照。页面中的 `structure-demo` 样本为带演示标记的合成文本与结构，不是真实 Blender 文件。GitHub Actions 中的 Playwright 用真实 Rust 生成证书与 Wasm 核验完整 / 部分披露、父节点变化、篡改拒绝和更换文件后的结果清除；未在本机运行构建或测试。
